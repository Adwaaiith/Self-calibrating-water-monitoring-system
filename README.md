# Self-Calibrating Smart Water Monitoring System

## Overview

The **Self-Calibrating Smart Water Monitoring System** is a Raspberry Pi–based platform designed to monitor important water-quality parameters while reducing the need for frequent manual sensor calibration.

The system uses a dedicated **reference-water tank** and electronically controlled water flow to periodically expose the sensors to a known reference condition. This allows the system to perform calibration checks and apply correction factors before returning to normal water monitoring.

The proposed system also includes an image-processing module for **E. coli detection**, where water samples are periodically positioned under a custom-built microscopic imaging setup using a belt mechanism.

## Key Objectives

- Continuously monitor water-quality parameters.
- Reduce manual sensor calibration.
- Use reference water for automated calibration.
- Automatically switch between monitoring and calibration modes.
- Compensate sensor readings for calibration drift.
- Detect E. coli using image processing and a stored/reference dataset.
- Provide a centralized Raspberry Pi–based control and processing system.
- Create a compact and cost-effective water monitoring platform.

## Water-Quality Parameters

### 1. pH

The pH sensor measures the acidity or alkalinity of the water.

**Purpose:**
- Monitor changes in water chemistry.
- Identify abnormal acidic or alkaline conditions.
- Provide a fundamental water-quality indicator.

### 2. Electrical Conductivity (EC)

EC measures the ability of water to conduct electrical current and is related to the concentration of dissolved ions.

**Purpose:**
- Monitor dissolved ionic content.
- Provide an electrical indication of water quality.
- Act as the primary measurement from which TDS can be estimated.

### 3. Total Dissolved Solids (TDS)

TDS can be estimated from EC using an appropriate conversion factor after calibration.

```text
EC Measurement
      │
      ▼
Temperature Compensation
      │
      ▼
Calibration / Conversion Factor
      │
      ▼
TDS Estimate
```

### 4. Amperometric Measurement

An amperometric sensor is planned for parameters such as **chlorine concentration**, depending on the final electrode configuration and calibration.

The sensor measures current generated by an electrochemical reaction and converts the measured signal into the required concentration.

### 5. E. coli Detection

The system includes a custom image-processing subsystem for detecting **E. coli**.

A belt mechanism periodically moves prepared water samples beneath a custom microscopic imaging setup. A camera captures the sample image, after which image processing/AI techniques can be used to compare the observed features with a reference dataset.

## Self-Calibration Mechanism

The main innovation of the project is the automated sensor calibration process.

### Normal Monitoring

During normal operation, the system directs the monitored water through the sensor chamber.

```text
Water Source → Pump → Electronic Valve → Sensor Chamber → Outlet
```

The sensors continuously acquire measurements and send the data to the Raspberry Pi.

### Sensor Self-Calibration

At a scheduled calibration interval, the electronic valve changes the flow path so that **reference water** is supplied to the sensor chamber.

```text
Reference Tank → Pump / Flow Control → Electronic Valve
                                      ↓
                                Sensor Chamber
```

The Raspberry Pi compares the sensor output with the expected response of the reference water and determines the required calibration correction.

A generic calibration model can be represented as:

```text
Corrected Value = Sensor Reading + Offset Correction
```

For sensors requiring gain/slope correction:

```text
Corrected Value = (Sensor Reading × Gain) + Offset
```

The exact calibration model and reference values will depend on the individual sensor and the calibration procedure implemented during testing.

### Reference Tank Filling

After reference water is used, the system can activate the required flow path to refill the reference tank. The supplied concept diagram identifies this as a separate operating state.

## Self-Calibration Advantages

- Reduces dependence on manual calibration.
- Helps compensate for sensor drift.
- Improves consistency of long-term measurements.
- Allows calibration to be performed without physically removing sensors.
- Reduces maintenance effort.
- Provides a repeatable calibration procedure.
- Makes the system more suitable for long-duration monitoring.

## Important Design Considerations

### Reference Water

The reference water must be prepared and stored under controlled conditions so that its expected properties remain sufficiently stable for calibration.

### Sensor-Specific Calibration

Different sensors require different calibration procedures. The calibration routine should therefore be implemented separately for pH, EC, and amperometric measurements rather than assuming one correction method works for every sensor.

### Temperature Compensation

Temperature can significantly affect measurements such as EC. Temperature sensing should therefore be included in the processing pipeline where required.

### Cross-Contamination

The reference-water path and monitored-water path must be designed to minimize contamination of the reference tank.

### Fluid Control

The pump and electronic valve must be synchronized with the sensor acquisition process to ensure that measurements are taken only after the required water has reached the sensor chamber.
